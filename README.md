# جدولي — مخطط الطالب الجامعي

نسخة أولية من منصة تنظيم جدول الطالب مبنية ببايثون. يحتوي المشروع الآن على **تطبيق سطح مكتب مستقل** بواجهة Tkinter عبر `desktop_app.py`، إضافة إلى نسخة Flask السابقة للتجربة عبر المتصفح.

## تشغيل تطبيق سطح المكتب

```bash
cd /home/ubuntu/jadwaly
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python desktop_app.py
```

ستظهر نافذة مستقلة للتطبيق ولا تحتاج إلى فتح متصفح. من داخلها يمكن إدخال المحاضرات، رفع PDF، مراجعة المحاضرات المستخرجة، مشاهدة التحليل، واستخدام المساعد.

## المزايا

- إضافة وحذف محاضرات يدويًا.
- عرض أسبوعي منظم بألوان مختلفة.
- تحليل محلي لأكثر الأيام ازدحامًا، الساعات الدراسية، أوقات الفراغ، التعارضات، مستوى الضغط، وأفضل يوم للمذاكرة.
- شات بوت عربي يعمل محليًا دون مفتاح، ويمكن ربطه بـ Google Gemini عبر متغير البيئة `GEMINI_API_KEY`.
- رفع جدول PDF المصوّر وتحويله إلى محاضرات منظمة عبر Gemini Vision، مع مراجعة النتائج قبل الإضافة.
- تطبيق سطح مكتب مستقل بواجهة Tkinter في `desktop_app.py`.
- تصدير الجدول إلى ملف JSON والاحتفاظ به في المتصفح.
- تصميم عربي RTL متجاوب مع الجوال والوضع الليلي.

## تشغيل نسخة Flask الاختيارية

```bash
cd /home/ubuntu/jadwaly
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

افتح `http://127.0.0.1:5000`.

### تفعيل Gemini اختياريًا

```bash
export GEMINI_API_KEY="ضع_المفتاح_هنا"
python app.py
```

المفتاح يبقى في الخادم ولا يظهر في الواجهة. في حال عدم وجوده، يستخدم التطبيق تحليلًا وردودًا محلية جاهزة.

> ملف `112.pdf` المرفق عبارة عن صفحة ممسوحة ضوئيًا، لذلك لا يكفي استخراج النص التقليدي منه. ميزة رفع PDF تستخدم تحويل الصفحة إلى صورة ثم قراءة الجدول بصريًا عبر Gemini.
